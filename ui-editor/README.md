# 🎨 UI-редактор BeautifulUI — как запустить

Редактор — это обычная HTML-страница. **Сборка, npm и интернет не нужны.**

---

## Способ 1 — двойной клик (самый простой)

1. Откройте папку `ui-editor`.
2. Дважды кликните по **`index.html`**.

Всё. Откроется браузер с редактором, слева — настройки, в центре — превью окна,
справа — готовый Lua-код.

> **Да, это правильный способ.** Страница не обращается к сети: темы лежат в
> `themes.js`, стили в `styles.css`, логика в `app.js` — все файлы рядом.

### Что может отличаться при двойном клике

| Браузер | Работает | Нюанс |
|---|---|---|
| **Chrome / Edge** | ✅ | Иногда блокирует автосохранение (`localStorage` для `file://`). Редактор покажет тост «Сохранение недоступно» — просто **скачайте `.lua`** перед закрытием вкладки |
| **Firefox** | ✅ | Автосохранение работает |
| **Safari** | ✅ | Автосохранение работает, но копирование может требовать клика по кнопке |
| **Мобильные** | ⚠️ | Открывается, но интерфейс рассчитан на мышь; удобнее через сервер |

**Если файл открывается как текст, а не как страница** — значит система
назначила `.html` текстовому редактору. Тогда используйте Способ 2 или 3.

## Способ 2 — локальный сервер (рекомендуется для Chrome)

В папке репозитория выполните:

```bash
node ui-editor/serve.mjs
```

Откройте **http://localhost:8080/ui-editor/**

Порт можно сменить:

```bash
node ui-editor/serve.mjs 3000
```

**Нужен Node 18+.** Зависимостей нет — ничего устанавливать не надо.

Альтернатива, если Node не установлен:

```bash
python3 -m http.server 8080
```

→ http://localhost:8080/ui-editor/

При сервере автосохранение работает всегда: адрес `localhost` считается
безопасным контекстом.

## Первый запуск: что делать дальше

1. **Задайте окно** — заголовок, подзаголовок, иконку, тему (11 штук из `SimpleUI.txt`).
2. **Соберите вкладки** — «+ Вкладка», затем элементы кнопками из блока «Элементы вкладки»
   (15 типов: кнопка, тумблер, слайдер, дропдаун, ввод, статус, график, кейбинд и т.д.).
3. **Настройте элемент** — кликните по нему в списке слева или прямо в превью.
   У кнопки есть **форма** (`Round`, `Pill`, `Square`, `Sharp`, `Circle`, `Wide`),
   у графика — **легенда** (пункты через запятую в виде `Имя=Значение`).
   Оба поля попадают в генерацию Lua: `Shape = "Pill"` и `Legend = {{Name=…, Value=…}}`.
4. **Укажите URL библиотеки** — поле «URL библиотеки (raw)»; подставьте свой адрес
   `SimpleUI.txt` (raw-ссылка GitHub). Без него в коде останется заглушка `ВАШ_URL`.
5. **Скопируйте код** — кнопка «Скопировать код» или «⬇» для скачивания `.lua`.
6. Вставьте результат в executor.

> Обратный путь тоже есть: **«Импорт Lua»** — вставьте код, сгенерированный
> редактором, и окно/вкладки/элементы восстановятся.

## 🎬 Сценарии: «когда сделал одно — сделай другое»

В верхней панели переключитесь на **🎬 Сценарии**. Это визуальный конструктор
логики: блоки на холсте, соединённые линиями, и свой Lua-код в каждом блоке.

### Как собрать сценарий

1. Нажмите блок в палитре сверху — он появится на холсте.
2. **Тяните от правой точки блока к левой точке другого блока** — появится линия.
3. Кликните по блоку — справа откроется инспектор с настройками и полем Lua.
4. Код сценариев автоматически вставляется в общий Lua (правая панель → «Lua-код»).

| Блок | Что делает | В Lua превращается в |
|---|---|---|
| **⚡ Событие** | что случилось: `Clicked`, `Changed`, `Submitted`, `Toggled`, `KeyPressed` | `element.Signal:Connect(function(value) … end)` |
| **🎬 Действие** | `Notify`, `Toast`, `Toggle`, `Set`, `Run`, `Custom` | `BeautifulUI:Notify(...)` / `element:Set(...)` |
| **❓ Условие** | ветвление по Lua-выражению | `if <выражение> then … else … end` |
| **⏱ Пауза** | задержка | `task.wait(n)` |
| **𝒇 Код** | произвольный Lua | как есть, с отступом |

### Правила работы

- **У события нет входа** — из него только выходят связи (логично: оно само запускает цепочку).
- **У остальных один вход** — вторая линия заменит первую.
- **Удалить связь** — клик по точке на линии.
- **Удалить блок** — ✕ в его шапке.
- **Несколько сценариев** — `+ Сценарий`, дублирование `⧉`, отключение `⏸` (выключенный не попадает в код).

### Пример: кнопка → уведомление + свой код

```
⚡ Кнопка «Начать» (Clicked)
   ├──▶ 🎬 Действие: Notify «Привет из сценария!»
   └──▶ 𝒇 Код: print("сработало:", value)
```

Превращается в:

```lua
pcall(function() btnAbc123.MouseButton1Click:Connect(function(value)
    if value == nil then value = true end
    BeautifulUI:Notify("Сценарий", "Привет из сценария!", 3, "Success")
    print("сработало:", value)
end) end)
```

Кнопка «✨ Пример» соберёт такой сценарий сама — удобно посмотреть, как это работает.

> **Важно:** элементы получают имена-переменные (`btnAbc123`, `toggleXyz`), чтобы
> сценарии могли на них ссылаться. Поэтому кнопки/тумблеры в коде теперь
> объявляются как `local btn… = Tab:Button(...)`.

## Частые вопросы

**Нужен ли интернет?**
Нет. Ни одного внешнего запроса: ни CDN, ни шрифтов из сети, ни аналитики.

**Почему превью не пиксель-в-пиксель как в Roblox?**
Это HTML-имитация: те же цвета, размеры, отступы и логика, но системные шрифты
вместо роблоксовых. Финальную проверку всегда делайте в игре.

**Где хранится мой проект?**
В `localStorage` браузера. При двойном клике в Chrome он может быть недоступен —
поэтому **скачивайте `.lua`**, это ваш бэкап.

**Как обновить список тем после правки `SimpleUI.txt`?**

```bash
node ui-editor/sync-themes.mjs
```

Перегенерирует `themes.js` из блока `local Themes` в `SimpleUI.txt`.

**Какие графики можно собрать?**
Семь типов: `line`, `area`, `bar`, `scatter`, `pie`, `radial`, `stacked`.
В инспекторе элемента есть поля «Стартовые данные», «Макс. точек» и «Оси и подписи» —
они превращаются в `Data = {...}`, `MaxPoints = n`, `ShowAxis = false`.

**Как добавить свой шрифт в редактор?**
Поле «Шрифт (Font)» принимает любое имя `Enum.Font`, ID из Marketplace
(например `12187365375`) или `rbxasset://…`. Список подсказок — 27 популярных.

## Если что-то не работает

| Симптом | Причина | Решение |
|---|---|---|
| Пустая страница | Браузер не загрузил `app.js` (файл перемещён) | Проверьте, что `index.html`, `styles.css`, `themes.js`, `app.js` лежат в одной папке |
| Пустая страница после правки `themes.js` | Синтаксическая ошибка в JSON-подобном объекте | Перегенерируйте: `node ui-editor/sync-themes.mjs` |
| Открывается текст файла | `.html` назначен текстовому редактору | Способ 2 (сервер) |
| «Сохранение недоступно» | Chrome + `file://` | Способ 2 или скачивание `.lua` |
| Копирование не сработало | Нет clipboard API | Кнопка «⬇» — скачивание файла |
| Превью пустое | Нет элементов в активной вкладке | Добавьте элемент или переключите вкладку |
