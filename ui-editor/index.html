Как это работает

Событие → Действие → Условие → Свой код. Тяните линию от правой точки блока к левой точке другого блока.

  • ⚡ Событие — что случилось (кнопка нажата, тумблер включён)
  • 🎬 Действие — что сделать (уведомление, включить что-то)
  • ❓ Условие — ветвление по Lua-выражению
  • ⏱ Пауза — task.wait
  • 𝒇 Код — произвольный Lua

Удалить связь — клик по точке на линии. Удалить блок — ✕ в его шапке.
